# Synqit CAD

Describe a part, get a parametric 3D model in the browser: sliders for every
dimension, STL / SCAD / DXF export, and real component sizes pulled from
Octopart. Part of Synqit ("you describe the hardware, we build it").

Setup for a fresh machine is in the repository root `README.md`; the deep
runbook is `../docs/LOCAL_SETUP.md`. Short version:

```bash
npm ci --ignore-scripts
node scripts/bootstrap.mjs --azure-key <AZURE_OPENAI_API_KEY>
npm run dev            # http://localhost:3000/cad
```

## How it works

- The model writes a complete OpenSCAD script (`build_parametric_model`).
- The browser compiles it with OpenSCAD-WASM in a Web Worker and renders a
  seven-view inspection sheet that goes back to the model; it rewrites until
  every view matches the request, then answers (`answer_user`).
- Every `name = value; // [min:step:max]` line becomes a slider. Moving a
  slider recompiles locally, no LLM call.
- **Parts** button in the composer: Octopart search (Nexar API), inserts the
  MPN, package and dimensions into the prompt.

## Stack

React 19, TypeScript, TanStack Start + Router, Vite, Tailwind, shadcn/ui,
Three.js / React Three Fiber, OpenSCAD-WASM, Supabase (Postgres, Auth,
Storage), Vercel AI SDK with Azure OpenAI (plus Anthropic / Google /
OpenRouter if keys are provided).

## Models

The picker lists the Azure deployments named in `VITE_AZURE_DEPLOYMENTS`
(default `gpt-5.1,gpt-5-pro`). When GPT-6 Astra is deployed on the resource,
add `gpt-6-astra` to that list and optionally set
`VITE_DEFAULT_MODEL=azure/gpt-6-astra`. No code change.

## Environment

See `.env.local.template`. Required: Supabase keys (generated by bootstrap),
the Azure key, `ENVIRONMENT=local`. Optional: guest mode, Google client id,
Synqit backend for "Continue with Synqit", Nexar credentials for Parts,
fal.ai for mesh mode.
