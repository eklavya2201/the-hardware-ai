# Find and export files

> Search, preview, filter, download, and export files created or uploaded across Adam tasks.

The **Files** page brings together files you uploaded and files Adam created.

## Open the Files page

Select **Files** in the sidebar. Files can be shown as a grid or list and grouped by task or chronologically.

You can find CAD files, drawings, documents, images, PDFs, presentations, spreadsheets, code, data, and other supported formats.

## Search and filter

Use the search field to match file names and related task titles. Refine the result by:

* file type;
* **By Adam** or **My uploads**;
* the product or app where the file came from; and
* task grouping or chronological grouping.

Select a task title beside a file to return to the conversation that produced it.

## Preview a file

Select a file to preview it. If that format cannot be previewed, download the original and open it in the appropriate application.

<Note>
  Open editable CAD files in their CAD application before approving a design change. The preview may not show feature history or other design details.
</Note>

## Download or export

Use the menu on a file to download the original or choose an available export format.

## Keep outputs traceable

Ask Adam to use descriptive filenames when a task will create several outputs. Keep the review discussion in the same task so teammates can see why each file was created.

<Tip>
  When Adam changes a design, ask for a short summary of what changed and what you should still review.
</Tip>
