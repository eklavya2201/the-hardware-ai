# Adam Fusion Copilot Install

Your AI copilot for Autodesk Fusion.

## Download the installer

Available for macOS and Windows

macOSWindows

After running the installer:

1

Create or open a file

In Fusion, create a new design or open an existing file so the workspace is active.

2

Adam opens on its own

Adam loads automatically: the palette docks on the right, and the ADAM button at the right end of the SOLID toolbar reopens it any time.

3

Sign in

Sign in and start chatting.

## Command line install

Prefer the terminal? Paste this instead.

macOS | Terminal

$ curl -sSL https://fusion.adam.new/install.sh | bashCopy

Windows | PowerShell

$ irm https://fusion.adam.new/install.ps1 | iexCopy

Then restart Fusion — Adam loads automatically, and the ADAM button at the right end of the SOLID toolbar reopens the palette any time.
