# Install Adam for Autodesk Fusion

> Install the Adam add-in and work with Fusion from the in-product panel or Adam web app.

Install the Adam add-in to work with your Fusion designs. You can start a task from inside Fusion or use the Adam web app while Fusion is open.

## Install the add-in

<Steps>
  <Step title="Download the installer">
    Open [fusion.adam.new/install](https://fusion.adam.new/install) on the macOS or Windows computer where Fusion is installed.
  </Step>

  <Step title="Run the installer">
    Close Fusion if requested, install Adam, and then restart Fusion.
  </Step>

  <Step title="Open Adam in Fusion">
    Open a design and select **Adam** from the Fusion toolbar. Sign in to Adam from the panel if prompted.

    <Frame caption="Select **Adam** in the Fusion toolbar to open the add-in.">
      <img src="https://mintcdn.com/adam-585915d9/SOvZH_gvRGaOooNN/images/product/fusion-toolbar-adam.png?fit=max&auto=format&n=SOvZH_gvRGaOooNN&q=85&s=61e24454c19bd621c8efe468d51bc881" alt="Fusion toolbar with the Adam add-in button" width="766" height="202" data-path="images/product/fusion-toolbar-adam.png" />
    </Frame>
  </Step>

  <Step title="Start a task">
    Ask Adam about the open design or selected geometry. The same task is also available in the Adam web app.
  </Step>
</Steps>

## If the Adam button is missing

In Fusion, press **Shift+S** to open **Scripts and Add-Ins**. Find **AdamFusion** under **Add-Ins**, select it, and choose **Run**. If it is not listed, rerun the installer and restart Fusion.

## Work with a Fusion design

Keep Fusion open while Adam works with a design. If Adam cannot see Fusion, open the intended design and select **Adam** from the toolbar.

Adam can use the open design and your current selection. In your message, still describe the geometry, constraints, and changes that matter.

<Tip>
  For an important edit, ask Adam to explain the planned changes and wait for your approval before applying them.
</Tip>

## Reinstall or update

Download the installer from [fusion.adam.new/install](https://fusion.adam.new/install) and run it again. Restart Fusion when installation finishes.

If the add-in runs but cannot reach Adam, check [Adam service status](https://status.adam.new), then sign out and back in from the panel before reinstalling.
