> Learn how to use Adam as an AI CAD copilot across tasks, files, CAD applications, PLM systems, and team workflows.

## What you can do in Adam

* **Review and change CAD.** Work with supported Onshape, Fusion, and desktop CAD applications.
* **Work with engineering information.** Review drawings, specifications, bills of materials, supplier information, and Arena records.
* **Research and create.** Search the web and create documents, presentations, images, spreadsheets, code, and other files.
* **Keep work organized.** Return to previous tasks, find generated files, share results, and schedule recurring work.

## Where to go

| When you want to...                   | Go to                                    |
| ------------------------------------- | ---------------------------------------- |
| Start something new                   | Select **New Task**.                     |
| Continue previous work                | Open **Tasks**.                          |
| Find or download a file               | Open **Files**.                          |
| Connect a CAD app or another tool     | Open **Integrations**.                   |
| Run a task later or repeat it         | Open **Scheduled**.                      |
