# Work with tasks

> Start, follow, organize, and share tasks in Adam.

A task keeps your conversation with Adam and its files together.

## Start a task

Select **New Task** in the sidebar and describe what you want to accomplish. Mention the relevant file or product and anything Adam should preserve or avoid changing.

You can give Adam more information in several ways:

* attach files with the composer button;
* drag files onto the task;
* paste text or an image;
* ask Adam to use a connected product; or
* start from inside Onshape or Fusion while viewing the design you want to work on.

## Follow a running task

Adam shows its progress in the conversation. It may pause to ask a question or request approval. Respond in the task to continue.

You can send another message while Adam is working. It will pick up the message when it is ready.

<Tip>
  For important changes, ask Adam to explain what it plans to do and wait for your approval before editing anything.
</Tip>

## Find and filter tasks

Open **Tasks** to search the workspace. Available filters include:

* **All**, **Mine**, and **Team** on shared teams;
* **Active**, **Needs input**, **Completed**, and **Scheduled**;
* where the task started, such as **Web**, **Onshape**, or **Fusion**; and
* the open CAD document when you are working inside a supported CAD panel.

You can rename, pin, or delete tasks from the task menu. Deleting a task is permanent, so review any files you still need first.

## Review files

Files open beside the conversation on larger screens. Use the file tabs to compare outputs without leaving the task.

Open [Files](/guides/files) from the sidebar to search across all tasks.

## Share a task

Task sharing is separate from team membership.

<Tabs>
  <Tab title="Invite people">
    Open the task's share control, select **Share**, enter an email address, and choose **Can edit** or **Can view**.

    A person with **Can edit** can send messages in that task. A person with **Can view** has read-only access.
  </Tab>

  <Tab title="Publish a link">
    Open the **Publish** tab and choose a plain public link or a password-protected link. Published links are read-only.

    Switch the task back to private to disable the link. If you change the password, visitors must enter the new one.
  </Tab>
</Tabs>

<Warning>
  Review every message and attachment before publishing. Anyone with access to the link can read the full conversation and open its files. Messages are not redacted.
</Warning>

## Continue related work

Reply in the same task when the earlier conversation, design, or files still matter. Start a new task for unrelated work or when you want to share it with different people.

When work spans several tasks that should use the same brief and reference files, organize it in a [project](/guides/projects).

For repeatable work, create a schedule from [Scheduled tasks](/guides/automations) instead of manually recreating the request.
